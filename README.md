# termuxa

Termux related Python helpers and official download links.

## Termux কী?
Termux হলো Android-এর জন্য একটি পাওয়ারফুল টার্মিনাল এমুলেটর + Linux environment।

## অফিসিয়াল Termux APK ইনস্টল করার উপায়

### ১. F-Droid থেকে (সবচেয়ে নিরাপদ)
- লিংক: https://f-droid.org/en/packages/com.termux/
- সরাসরি APK ডাউনলোড করতে পারো।

### ২. GitHub Releases থেকে
- অফিসিয়াল রিপো: https://github.com/termux/termux-app/releases
- Android 7+ এর জন্য `apt-android-7` + `universal` ভার্সন নাও।

> শুধুমাত্র অফিসিয়াল সোর্স থেকে ডাউনলোড করো।

## Python স্ক্রিপ্ট
`download_termux.py` চালিয়ে অফিসিয়াল লেটেস্ট APK ডাউনলোড করতে পারো।
